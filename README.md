# Models de documents administratius i comercials

Sis models editables que es poden obrir amb LibreOffice Writer o qualsevol navegador:

1. [Anunci](documents/01_anunci.html)
2. [Carta](documents/02_carta.html)
3. [Certificat](documents/03_certificat.html)
4. [Circular](documents/04_circular.html)
5. [Citació](documents/05_citacio.html)
6. [Contracte de compravenda](documents/06_contracte.html)

Els camps entre claudàtors s'han de completar. Les dates, dades, terminis i referències legals s'han de verificar abans d'utilitzar els models. La citació és fictícia i el contracte és només didàctic; cap dels models no té validesa administrativa o jurídica per si mateix.

Els fitxers HTML es poden obrir amb LibreOffice Writer i desar en format ODT.
