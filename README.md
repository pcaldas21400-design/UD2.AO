# Models de documents administratius i comercials

Sis models editables en format **OpenDocument Text (.odt)**, preparats per obrir amb LibreOffice Writer:

1. [Anunci](documents/01_anunci.odt)
2. [Carta](documents/02_carta.odt)
3. [Certificat](documents/03_certificat.odt)
4. [Circular](documents/04_circular.odt)
5. [Citació](documents/05_citacio.odt)
6. [Contracte de compravenda](documents/06_contracte.odt)

Els camps entre claudàtors s'han de completar. Verificau les dates, les dades, els terminis i els imports abans d'utilitzar els models. El certificat només s'ha d'emetre amb dades comprovades i signatura autoritzada. La citació és fictícia i el contracte és didàctic: no tenen validesa administrativa o jurídica per si mateixos.
