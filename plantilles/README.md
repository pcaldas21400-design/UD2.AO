# Plantilles de documents administratius (UD2.AO)

Plantilles professionals creades amb LibreOffice / odfpy en català, seguint models de documentació administrativa.

## Fitxers

| Fitxer | Tipus de document |
|--------|-------------------|
| `01_Anunci_Escola_Municipal_Mao.fodt` | Anunci de l'Ajuntament de Maó – obertura termini de matriculació (Ceràmica, Música, Dibuix) |
| `02_Carta_Comanda_Xerox.fodt` | Carta de l'IES Joan Ramis i Ramis sol·licitant 2 multifuncions a Xerox de Menorca |
| `03_Certificat_1r_SMX.fodt` | Certificat del secretari del centre que l'alumne cursa 1r SMX |
| `04_Circular_IBI_Recaptacio.fodt` | Circular del Servei de Recaptació sobre termini de pagament de l'IBI |
| `05_Citacio_Hisenda_Model_061.fodt` | Citació de l'AEAT per signar document del Model 061 |
| `06_Contracte_Compravenda_Vivenda.fodt` | Contracte de compravenda d'una vivenda |

## Com obrir-les

- **.fodt** (Flat ODF): XML pla. Obre'l directament amb LibreOffice Writer. Després pots desar-lo com a `.odt` normal.

## Estils aplicats

- **Tipografia**: Liberation Sans (títols) i Liberation Serif (cos)
- **Mides**: títols 16 pt, cos 11 pt, peus 8 pt
- **Colors corporatius** per a cada tipus d'entitat
- **Marges A4**, capçaleres, peus amb número de pàgina
- **Ortografia** revisada en català (placeholders `[...]` per omplir)
