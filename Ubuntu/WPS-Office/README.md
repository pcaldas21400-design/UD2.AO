# WPS Office – Plantilles (.docx)

Documents creats per a WPS Office / Microsoft Word en format **.docx**.

| Fitxer | Contingut |
|--------|-----------|
| 01_Convocatoria_Reunio.docx | Convocatòria de reunió – Club Marítim de Maó (dilluns 20h, sala d'actes) |
| 02_Curriculum_Vitae.docx | Curriculum vitae modern (perfil SMX) |
| 03_Factura.docx | Factura d'empresa (multifuncions, tòner, cable, instal·lació) |
| 04_Solicitud_Instancia.docx | Sol·licitud / Instància a concurs-oposició plaça administrativa |
| 05_Diari_Dues_Columnes.docx | Document a dues columnes – estil diari comarcal |
| 06_Diploma.docx | Diploma millor alumne/a de 1r SMX (apaïsat) |
| 07_Document_Fons.docx | Document amb fons corporatiu (preparat per imatge de fons) |

## Estils aplicats
- Tipografies: Arial, Calibri, Georgia, Times New Roman
- Capçaleres i peus de pàgina
- Marges, colors corporatius, taules, dues columnes, diploma apaïsat
- Ortografia en català

Obre'ls amb **WPS Office Writer** o Microsoft Word / LibreOffice.
