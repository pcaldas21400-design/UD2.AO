# Plantilles – Documents administratius (UD2.AO)

Carpeta amb les 6 plantilles en format **.odt** / **.fodt** (LibreOffice / OpenDocument).

| Fitxer | Contingut |
|--------|-----------|
| 01_Anunci | Anunci de l'Ajuntament de Maó – termini de matriculació (Ceràmica, Música, Dibuix) |
| 02_Carta | Carta de l'IES Joan Ramis i Ramis sol·licitant 2 multifuncions a Xerox de Menorca |
| 03_Certificat | Certificat del secretari del centre – cursant 1r SMX |
| 04_Circular | Circular del Servei de Recaptació – termini de pagament de l'IBI |
| 05_Citacio | Citació d'Hisenda per signar el Model 061 |
| 06_Contracte | Contracte de compravenda d'una vivenda |

## Com obrir

- Els fitxers **.fodt** (Flat ODF) s'obren directament amb LibreOffice Writer.
- Un cop oberts: **Fitxer → Anomena i desa → ODF Text Document (.odt)**.

## Estils

- Tipografies Liberation Sans / Serif
- Capçaleres i peus de pàgina amb número de pàgina
- Marges A4, colors corporatius, text justificat
- Ortografia en català (placeholders `[...]` per omplir)
