# WPS Office – Plantilles (.docx)

## Com obtenir els 7 documents .docx

```bash
cd Ubuntu/WPS-Office
chmod +x reconstruct.sh
./reconstruct.sh
unzip WPS_Plantilles.docx.zip
```

Això crearà els 7 fitxers:
- 01_Convocatoria_Reunio.docx
- 02_Curriculum_Vitae.docx
- 03_Factura.docx
- 04_Solicitud_Instancia.docx
- 05_Diari_Dues_Columnes.docx
- 06_Diploma.docx
- 07_Document_Fons.docx

Obre'ls amb WPS Office o LibreOffice.
