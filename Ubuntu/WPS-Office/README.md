# WPS Office – Plantilles (.docx)

Documents creats per a **WPS Office Writer** (compatible amb Microsoft Word i LibreOffice) en format **.docx**.

## Com obtenir els 7 documents

Des del terminal (dins de la carpeta del repositori):

```bash
cd Ubuntu/WPS-Office
chmod +x decode.sh
./decode.sh
```

Això descomprimirà / desxifrarà els fitxers i generarà els 7 `.docx` a punt per obrir.

## Contingut de les plantilles

| Fitxer | Contingut |
|--------|-----------|
| 01_Convocatoria_Reunio.docx | Convocatòria de reunió – Club Marítim de Maó |
| 02_Curriculum_Vitae.docx | Curriculum vitae modern |
| 03_Factura.docx | Factura d'empresa (productes TIC) |
| 04_Solicitud_Instancia.docx | Sol·licitud / Instància a concurs-oposició |
| 05_Diari_Dues_Columnes.docx | Document a dues columnes (estil diari comarcal) |
| 06_Diploma.docx | Diploma millor alumne/a de 1r SMX |
| 07_Document_Fons.docx | Document amb fons corporatiu |

Obre'ls amb **WPS Office Writer**.
