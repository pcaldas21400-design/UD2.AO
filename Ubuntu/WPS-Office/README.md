# WPS Office – Plantilles (.docx)

Documents en format **.docx** per a WPS Office / Word.

## Com obtenir els .docx

Els fitxers estan en base64. Descodifica'ls:

```bash
cd Ubuntu/WPS-Office
chmod +x decode.sh
./decode.sh
```
